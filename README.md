# Профимер — опросник для руководителей

Простой статический сайт-опросник. Без сервера, без базы данных, без авторизации —
всё работает в браузере пользователя. Ответы собираются в ZIP-архив
(`answers.json` + `answers.xlsx` + папка `files/` с приложениями), который респондент
скачивает и присылает вам сам (email, Telegram и т.д.).

## Структура

```
index.html   — разметка страницы
style.css    — стили (поддержка тёмной темы, адаптивная вёрстка)
app.js       — вся логика: вопросы, автосохранение, сборка ZIP
README.md    — этот файл
```

Внешние библиотеки подключены через CDN (cdnjs) прямо в `index.html`:
`jszip` (сборка ZIP) и `xlsx` / SheetJS (сборка Excel-файла внутри архива).
Интернет для их загрузки нужен один раз при открытии страницы.

## Перед публикацией — обязательно поправьте

Откройте `app.js`, найдите в самом начале константу:

```js
const CONTACT_INSTRUCTION = "После заполнения нажмите «Скачать мои ответы (ZIP)» и отправьте архив на email или в Telegram координатору проекта «Профимер».";
```

Впишите туда реальный email или Telegram, куда респонденты должны присылать архив —
сейчас там placeholder-текст.

При необходимости там же, в начале `app.js`, можно отредактировать сам список
вопросов (массив `BLOCKS`) — блоки и вопросы взяты один в один из вашего ТЗ (32 вопроса,
блоки А–З).

## Как проверить локально

Файлы можно просто открыть двойным кликом (`index.html`) — сайт полностью статический
и работает без сборки. Либо поднять локальный сервер (не обязательно, но иногда браузер
строже относится к file:// — тогда так надёжнее):

```bash
# любой из вариантов
npx serve .
# или
python3 -m http.server 8080
```

и открыть `http://localhost:8080` (или порт, который выведет команда).

## Как опубликовать

Это обычный статический сайт из трёх файлов — подойдёт любой статический хостинг.
Самые простые варианты:

### Netlify (проще всего, без Git)
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащите папку с этими тремя файлами в окно браузера
3. Через несколько секунд получите рабочую ссылку

### Vercel
```bash
npm i -g vercel
vercel deploy
```
(в папке с файлами; для статического сайта без фреймворка Vercel всё определит сам)

### GitHub Pages
1. Создайте репозиторий, залейте туда `index.html`, `style.css`, `app.js`
2. Settings → Pages → Source: ветка `main`, папка `/root`
3. Сайт появится на `https://<ваш-логин>.github.io/<репозиторий>/`

## Важно про данные

Всё хранится **только в браузере пользователя** (localStorage — для черновика,
ZIP-архив — для готового ответа). На ваш сервер ничего не уходит и уходить не может —
на сайте вообще нет бэкенда. Это значит, что каждый респондент должен сам
прислать вам скачанный архив любым удобным способом.
